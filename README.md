## 🎨 Customization

The main visual theme is controlled through CSS variables in `style.css`.

```css
:root {
  --blue: #2457ff;
  --cyan: #00e5ff;
  --purple: #9b4dff;
}
```

You can customize:

- Primary and secondary neon colours
- Background and borders
- Glow intensity
- Card size and border radius
- Input and button styles
- Typography
- Responsive breakpoints

---

## 📱 Responsive Design

The interface adapts to different screen sizes.

**Desktop:** The login form and social-login section appear side by side.

**Mobile:** The layout changes to a vertical structure with compact social-login buttons.

No separate mobile project is required.

---

## 🔐 Authentication Notice

This project is a frontend UI implementation only.

It does not provide real user authentication, password storage or account management.

The Google, Apple and Facebook buttons are UI placeholders and are not connected to their authentication services.

For production websites, connect the interface to a secure backend authentication system.

Never store user passwords directly in frontend JavaScript or HTML.
