## 🎨 Customization

The main visual controls are at the top of `style.css`:

```css
:root {
  --bg: #050711;
  --blue: #2457ff;
  --cyan: #00e5ff;
  --purple: #a855f7;
  --text: #f7f9ff;
  --muted: #7d89a8;
}
```

Change these variables to create your own theme without rewriting the whole stylesheet.

### Quick theme ideas

- Blue + cyan → technology / developer UI
- Purple + cyan → creative / AI UI
- Green + cyan → cyber / terminal UI
- Red + purple → gaming UI

## 📱 Responsive Design

The interface automatically adapts to different screen sizes.

**Desktop:**  
Two-column layout with the login interface and futuristic visual panel.

**Tablet:**  
The visual panel is removed to give the form more space.

**Mobile:**  
Single-column compact layout optimized for touch screens.

## 🔐 Authentication Notice

This repository contains a **front-end UI demo only**.

It does **not** provide real authentication.

The Google, Apple and Facebook buttons are interface placeholders and are not connected to OAuth providers.

For production use:

- Use a secure backend.
- Send credentials through HTTPS.
- Never store plain-text passwords.
- Use secure password hashing on the server.
- Add proper session/token handling.
- Connect OAuth providers through their official authentication flows.
